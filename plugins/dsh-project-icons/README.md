# 项目图标与状态靠右

`@local/dsh-project-icons` 提供侧栏项目图标、会话状态布局和会话标题气泡。

- Host 通过原有认证接口 `/api/project-icon` 提供已登记工作区内的项目图标，保留图标发现与缓存规则。
- Client 在侧栏会话行首显示项目图标；找不到图标时使用当前的圆形彩色字母兜底。
- Client 在侧栏工作区行用同一批项目图标替换原来的文件夹图标；项目没有图标时保留文件夹图标，行内几何不变。
- 会话行暂时拿不到目录时，Client 改走 `/api/session-icon?session=<id>`，由 Host 从 DSH 会话元数据查找已登记工作区的图标。
- 状态标记显示在行尾；非空闲状态下隐藏相对时间，悬停时由原生操作入口接替行尾空间。
- 悬停侧栏会话标题时，原生气泡显示所属项目名称，项目名称一行保留完整路径。未归入工作区的会话省略项目一行。
- 展开左侧栏后，可沿原有分隔线拖到最窄 176 px。拖拽时侧栏内容和 Windows 标题栏同步调整。

图标使用伪元素和行内 CSS 变量，避免 React 更新会话行时丢失手工插入的节点。

## 生效方式

Host 与 Client 两半都从本目录以 `link:` 安装。Host 逻辑在插件重新加载时生效；`client.js` 的改动需要重开窗口或重启桌面版，让页面重新加载客户端资源。升级到 1.2.0 前，先在 DSH 插件管理中卸载独立的「标题气泡显示项目」（`@local/dsh-title-project-tip`），升级后由本插件注册会话气泡扩展。

## 配置与维护

桌面配置只加载 `@local/dsh-project-icons`，不再同时加载 `@local/dsh-row-status-right`。同一包中必须一起维护 Host 图标接口和 Client 图标、状态布局，避免接口与显示逻辑分散在不同插件中。

本次沿用正在使用的 Client 实现，保留圆形和彩色字母图标；不回退到较早的 `@sylen/dsh-project-icons` 合并草稿。

## 验收（2026-11-15）

复用现有 DSH 服务，通过原生插件开关重新识别新增 Client 元数据，无需重启服务。无头浏览器确认合并包样式仅加载一份、旧包样式未加载、实际项目图标接口返回 PNG，项目图标在悬停时保持稳定。Client 与合并前正在使用的实现仅插件身份不同。
