# 预览元素引用

在 DeepSeek Harness 桌面版 `0.2.2-rc.5` 中，打开「插件 → 添加插件」，选择本目录并启用插件。右侧面板打开「浏览器」标签并加载网页后，「在系统浏览器中打开」按钮左侧会出现「选取元素」指针箭头。

点「选取元素」，将鼠标移到网页上查看蓝色高亮，点击目标即可将其添加到当前对话的输入框。选取时，点击用于采集引用，按 Esc 或再次点击工具栏按钮可以退出。要选其他元素，再开启一次选取。引用在输入框内显示为简短标签，悬停可查看完整内容，也可点击标签上的关闭按钮移除。引用随你手动发送的消息提交。

引用包含页面标题、网址（省略身份信息、查询参数和片段）、元素标签、CSS 定位和简短文本。可点选主文档、开放的 Shadow DOM 和同源 iframe 内的元素，引用会记录嵌入页面和元素的定位。跨域 iframe 可以作为整体选中。插件省略表单值和原始 HTML，支持与「共用右侧面板」同时使用。
